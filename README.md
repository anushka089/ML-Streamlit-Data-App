
# Machine Learning Data App

## Project Description
A web-based data application developed using Python and Streamlit.

## Features
- Upload CSV datasets
- Preview uploaded data
- Display number of rows and columns
- Check missing values

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Installation

Install the required libraries:

pip install -r requirements.txt

## Run the Application

streamlit run app.py
